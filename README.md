# ALT100 SMC Personal — ربات شخصی سیگنال تلگرام

این پروژه فقط برای یک دریافت‌کننده است. **هیچ اشتراک، پرداخت، فروش، پنل مشتری یا ارسال گروهی ندارد.**

## عملکرد
- انتخاب حداکثر ۱۰۰ جفت‌ارز USDT اسپات با حجم مناسب و بدون BTC/استیبل‌کوین‌ها
- ساختار 1H (HH/HL, LH/LL, BOS)، نواحی 15M (FVG, OB, liquidity sweep, BOS retest)
- تریگر تأییدشده 5M و هشدار فقط پس از بسته‌شدن کندل
- فیلتر گپ کندل، تازگی داده، اسپرد و اختلاف قیمت از تریگر؛ لغو هشدار در صورت شکست اعتبار
- قیمت ورود شرطی روی پولبک، حد ابطال و دو هدف مرجع؛ «ورود تضمین‌شده» نیست
- ذخیره شناسه ستاپ در state/signals.json جهت جلوگیری از تکرار
- فقط ارسال تلگرام؛ بدون دریافت کلید معامله و بدون ثبت سفارش

## نصب ساده از اندروید
1. در GitHub مخزن جدید Public با نام `alt100-smc-personal` بسازید؛ گزینه README روشن باشد.
2. فایل `ALT100-SMC-Personal.zip` را *همان‌طور که هست* در ریشه مخزن Upload و Commit کنید.
3. در وب GitHub با `Add file > Create new file` مسیر `.github/workflows/signal-bot.yml` را بسازید و محتویات فایل جداگانه `ALT100-SMC-Personal-Workflow.yml` را در آن کپی و Commit کنید.
4. در `Settings > Actions > General` دسترسی `Read and write permissions` را برای Workflow permissions فعال کنید (اگر پشتیبانی می‌شود).
5. در Actions، Workflow را انتخاب کرده، `Run workflow`، گزینه task=`install` را اجرا کنید؛ فایل ZIP باز می‌شود، تست‌ها اجرا و کدها Commit می‌شوند.
6. از @BotFather توکن را بگیرید، به ربات خود `/start` بدهید، شناسه عددی خصوصی خود را از @userinfobot بگیرید.
7. در `Settings > Secrets and variables > Actions` دو Repository secret به نام `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` بسازید. هرگز توکن را در مخزن عمومی یا چت نفرستید.
8. Workflow را با task=`scan` اجرا کنید و پس از تیک سبز، پیام فعال‌سازی را در تلگرام بررسی کنید.

## محدودیت‌ها
- اسکن زمان‌بندی‌شده GitHub Actions پنج‌دقیقه‌ای **ممکن است تأخیر داشته باشد یا اجرا نشود**؛ سرویس بلادرنگ نیست. برای اسکالپ حساس به ثانیه‌ها، سرور دائما فعال بهتر است.
- حتی تست‌های نرم‌افزاری موفق، دقت ورود/وین‌ریت/سوددهی را اثبات نمی‌کنند. قبل از معامله واقعی فورواردتست و لحاظ کارمزد/لغزش لازم است.
- اگر بیش از یک‌سوم ارزها خطای دریافت داده داشته باشند، ارسال لغو می‌شود؛ برای داده ناقص هشدار ساختگی ارسال نمی‌شود.
- `SELL_WARNING` هشدار ضعف بازار اسپات است، سیگنال شورت یا فیوچرز نیست.
- اگر امکان Commit فایل state با دسترسی workflow وجود نداشته باشد، گزارش خطا را بررسی کنید. هیچ توکنی در کد ذخیره نشده است.
